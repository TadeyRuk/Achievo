# Level 4 tester checklist

Share this with classmates who can help diversify on-chain payouts on **Stellar Testnet**.

## Before you start

1. Install [Freighter](https://www.freighter.app/) (or another Testnet-compatible wallet).
2. Switch the wallet network to **Testnet**.
3. Fund the account (Friendbot / in-app Fund button).
4. Open the live app: [achievo-rust.vercel.app](https://achievo-rust.vercel.app).

## Run one payout

1. Connect your wallet.
2. Enter your name if prompted.
3. Submit a real activity description (tutoring, workshop, volunteering, event, or participation).
4. Sign the ownership challenge in your wallet.
5. Wait for the pipeline to settle — note the transaction hash.
6. Optionally rate the payout in the feedback sheet.

## Limits

- **1 reward per wallet per day** (and per IP per day).
- Use a **unique Testnet wallet** per tester when possible.
- Vague one-liners may be rejected or earn a low effort score — be specific.

## Verify

- Confirm the tx on [StellarExpert Testnet](https://stellar.expert/explorer/testnet).
- Contract: `CCQVKUU2AYYWLKEUNZ47NXYLUB4SLN5YEB3EHQ76TCI5X4K5VEIW5PDS`.
- History tab should refresh with the on-chain entry within ~15 seconds.
